# Actual-consumer skin selection r7

The sole new startup switch is skin_actual_consumers, default false. Puppet keeps its inherited visual preservation (culling and flat-light policy). When enabled, the blanket late-overlay capability no longer forces live mutable meshes. Explicit frozen, electric and ambient-refresh guards retain serial continuation exactly where current consumers read those meshes. Active electric consumers are declared before body preparation, including Hatter late-pass shocks. Attachments remain inside their parent's consumer guard. Existing worker arenas, kernel arithmetic, wait/unwind behavior and owned publication order are retained; no new thread or deferred mutable shared-model reference is introduced.

Unsupported material recipes, topology mismatch, missing identity and full arenas continue through exact serial fallback. Facial/blink/hidden mutations happen before capture; UV is snapshotted into each owned bank, and every hidden mesh is restored before another actor uses the shared model. No render or simulation frequency changes. Palette remains disabled in the baseline.

phase_census remains separately default off. Schema 2 adds six nested scopes and fixed per-actor reason/vertex rows. Workers record service time into their existing disjoint task descriptor only when the census is active; main reads it after wait. No worker accesses the main-thread census TLS. Export and serialization occur after the benchmark.

The host-only sim_maps_probe oracle hashes every vertex position/normal/color/UV word and index, and submitted geometry, texture pixels, policy and uniform bits in order. Expensive proof mode is excluded from timing and native builds. Host moving views use a deterministic scripted camera. All assets stay external to the repository and package.

The console package has eight census-off wall measurements plus four required separate diagnostic measurements, split into two fully restored six-launch admissions to preserve the 150-minute cap. Benefit requires BOTH Pandemonium oriented median B-A deltas below -1 ms and BOTH Hedge3 deltas at or below +1 ms. No console operations run during preparation.

Census State keeps the fixed 180 rows and 128 actor slots per row in one startup Box, initialized field by field without a large native constant. No census state is initialized in the default-off arm. Host State layout is 1,658,232 bytes; native heap request/layout must be read from its own build, not assumed from the host.
