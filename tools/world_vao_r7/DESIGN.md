The independent variable is `world_vertex_input`, default false. Both arms use identical world draw lists, order, geometry buffers, shaders, textures and uniform values. At map load, Miniquad caches native VAOs by resolved shader attribute layout and vertex-buffer identities. Resolved layout metadata is shared between descriptors. Per draw it selects the VAO and applies the existing live texture/sampler/index bindings and uniforms. No draw packing, sorting, merging or uniform persistence is enabled.

The dynamic attribute cache belongs to the original VAO. Cached VAOs never overwrite it. The world pass resets to that VAO before leaving; ordinary binding and buffer methods also reset. The index binding cache is invalidated on a VAO switch because index state is VAO-local. A descriptor checks the live resolved layout and buffer content revisions; updates and deletion force allocation-free fallback. Reconstruction is explicit load-time work. Shader identity itself need not match if all resolved attribute slots/formats/strides/offsets/divisors match; sampler/uniform ownership is reapplied by the existing state cache.
