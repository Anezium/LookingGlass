# Ant GPU cost: certified default-cutout actors (2026-11-17)

`actor_cutout_discard_free` (default off) routes non-effect actor packets with the default
model cutout (`Cutout=4`, reject alpha < 0.35) to the existing discard-free program when the
rejection is certified unreachable: all-opaque texture certificate, `Gain.a == 1`, every
vertex alpha 255, no dissolve, no ghost. Geometry, order, textures, uniforms, blend and depth
state are unchanged; only the four `discard` statements are absent from the program.

Why it exists: `actor_discard_free_shader` only covers uncut (`Cutout=0`) environment-material
surfaces. The army ants, the antlion, Alice and most characters use the default cutout on an
opaque skin, so they stayed on the program that contains `discard`.

The key is independent of `actor_discard_free_shader`; both can be on. Uncut ordinary actors
(for example ladybugs) stay on the original program: the earlier broad selector that included
them failed the strict pixel oracle on potears1.

Host proof and the console package live outside Git, in the task evidence folder.
Console speed and picture are measured by the device slot only.
