# Live coverage survey
The survey is opt-in and uses the ordinary viewer, gameplay clocks, controllers, funded weapons and renderer.
Without a manifest, normal startup, input, saves and rendering keep the pkg-2 paths.

## Entry and isolation
On Vita, stage `ux0:data/alice/private/coverage_survey.json`.
On a host built with `vita_renderer`, pass `--coverage-survey <manifest>`.
Hosts do not discover an unrequested manifest.
The manifest is version 1, rejects unknown fields, and limits file size, scene count, IDs, tick range and durations.
Paths to checkpoints are relative to the manifest directory and must have an explicit SHA-256.
Checkpoints are copied into a unique run/cell Store as Slot 1, read explicitly, and auto-resumed.
The survey does not write quick, auto, finale or clean-quit saves.

Output is `<manifest-directory>/coverage-results/<run-id>-<timestamp>/`.
An existing directory or CSV name fails instead of overwriting earlier evidence.
A five-minute maximum cell/load watchdog also covers synchronous loading; the overall limit is two hours.

## Manifest fields
Top-level fields are version, run_id, repeats (1–3), overall_timeout_s, seed_policy,
debug_fixtures and scenes. The supported seed policy is `restore-checkpoint-or-authored-load`.
A scene defines id, family (V0/C1/C4/F4/W/E/B/T), map, entry, checkpoint, view, warmup_s,
timed_s, timeout_s, epochs, school_clubs, queen_fixture, tape, expected and uncovered.
Use `null` for absent checkpoint/view/Queen fixture/uncovered reason.
An uncovered reason must explain the missing reproducibility or activity predicate.

A view supplies feet, yaw/pitch in radians and third_person.
A tape sample supplies a 120-Hz tick index, movement/look axes, jump, run, primary,
alternate, select (zero-based weapon index), use_action and skip. Values persist until the next sample.
Normal frame dt and the physics accumulator are retained; the survey does not force a fixed rendered dt.
Use holds long enough to be observed by a presented frame. The normal Buttons/cooldown/charge/release paths consume attacks.
Enemy acquisition/attacks and actual shots/impacts/deaths must prove effectiveness; requested inputs alone are insufficient.

School fixtures require debug_fixtures, skool1 first visit, and exactly one or four frozen [x,y,z,yaw] guard placements.
The source guard rig/controller is shared across distinct actor IDs; floor support and sight/view predicates are validated.
School epochs reset saved state, clocks, particles and audio outside timed windows. Enemies have normal health and can die.
Queen fixtures are bounded module-local stages derived from existing render checks; their state advances normally after staging.
Natural route checkpoints are generated by `--coverage-prepare-fixtures <isolated-directory>`.
Preparation is not live validation and is not a timing result.

## Evidence
Each run records the effective manifest, renderer/simulation identity, actual loadout/difficulty, checkpoint hash,
scene/repeat status, validation/progress traces, raw light CSVs, epochs and load/memory milestones.
The ring stays bounded at 60 rows and exports completed windows at the pkg-2 cadence; partial final windows contain only unexported rows.
The next frame boundary completes the previous wall sample before a scene/epoch finishes.
Exports remain in the primary wall distribution, and export frames are labelled.

Added mutually exclusive coarse spans cover events/movers, AI/combat, Alice/weapons,
particles and audio. They leave other work in an unscoped remainder.
Deferred-tail CPU accounting splits at CPU boundaries and adds only the portion outside the CPU span.
The repair is opt-in, preserving absent-manifest instrumentation semantics.

Content counts cover generic guard activity, unique NPC models, weapon shots/impacts, puffs,
skin worker service/arena use, visible world groups/cluster, sweeps, and supported controller-owned content.
Owner-specific counters must not be equated with all loaded NPC placements or total GPU draws.
Audio counts report registered sources and decoded cache bytes, not an audible-output proof.
Vita memory is sampled at milestones and once per second; free newlib arena and vitaGL pools are distinct.
Sample extrema do not establish an allocation peak between samples; unavailable allocation-failure/contiguous-block counters remain null.
Linux deferred GL hooks remain unavailable, so host HUD/present attribution is incomplete.

Use the supplied PROTOCOL and summarize.py. Host rehearsal proves mechanics and fixture predicates;
console wall timings, playback, peak-fit and visual acceptance remain console-owner work.

The first cold presented frame is preserved in raw CSVs with `timed=0`. Its lazy scene/pipeline construction is startup work. The settle/encounter clock begins only after that presentation has completed. School cells use a separate `-setup` segment and restore their original gameplay snapshot outside the first timed epoch. Subsequent weapon first-use stalls inside epochs remain retained. This prevents a slow cold desktop frame from consuming an entire short encounter before it can begin.

## Native Mac validation
Manifest-enabled hosts request a non-resizable 960×544 window. Their world camera and cinematic FOV conversion use the fixed 960/544 console aspect, independently of asynchronous window resize events. Actual window dimensions and projection aspect are recorded. Without a manifest the ordinary host window and camera policy remain unchanged; Vita keeps its normal fixed-screen aspect.

Host verification reads the last retained scaled 3D target after the final presented row has been completed and flushed. These images exclude HUD, advance no simulation and add no readback inside a retained window. Reading the default framebuffer after the loop would instead capture the next frame's clear. The host image audit rejects uniform/blank evidence. This diagnostic requires the retained scaled target used by the supplied stock configuration.

Guard activity combines saved ranged-shot counts with observed successful club contacts. Club contacts use ephemeral feedback and per-epoch survey accumulation; they never increment the saved ranged-shot counter, which also seeds death FX. A contact counts only when normal range, facing, height and line-of-sight tests permit the ordinary strike. Requested inputs and attempted swings are insufficient.

`tools/coverage/run-mac.py` coordinates campaigns through the shared timing lock, preserves load samples and rejects unqualified timing evidence. `audit-fixtures.py` checks raw epochs, states, guard identities and nonblank images. `parity-mac.py` compares the existing 109 frozen fixtures against a separately built pkg-2 baseline, without claiming timings. `build-mac-package.py` applies the pinned pkg-2 SDK, release flags and ELF/import/ZIP/hash checks on the Mac. Fixture approval still requires the final manifest's full rehearsal; the tools alone do not establish coverage or console acceptance.
