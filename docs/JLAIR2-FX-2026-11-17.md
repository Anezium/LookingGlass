# jlair2 fight: lean programs for additive effect packets (2026-11-17)

Two keys, both default off.

`fx_add_lean` routes additive effect packets (`Blend::Add` and `Blend::AlphaAdd` from
`render_fx::effect` and the world puff batches: fire breath, sparks, glows) to a fragment
program that keeps the full program's texture read, the alpha product, one cutout test,
`diffuse.rgb*Gain.rgb`, the vertex colour product and the unchanged `fogged` call. A packet
is admitted when it is an effect, unlit, unclamped, uncut, with no dissolve, ghost, power
tint or filter fade, `FxModel = 1` and `FogMode = 1`. For such a packet every removed line
of the full program is unreachable or multiplies by one or adds zero: both `gl_FragCoord`
discards, the cutout chain, the light atlas fetch, the lighting factor, the dynamic
lights, the tints, the filter fade and the sky backdrop fetch.

The kept cutout test is `if(Cutout>0.5&&alpha<=0.0)discard;`, the first clause of the full
chain without its upper bound. An admitted packet has `Cutout = 0`, so it never runs. It
is there because a program with no alpha-dependent `discard` makes the host GPU shade tiny
sprites through another path: a first version without any `discard` failed the strict
pixel oracle on both potears1 tapes (waterfall drops a few pixels wide, up to 9/255 on
about a hundred pixels per frame, with identical state, packets and per-draw fragment
counts). Bisected with `LOOKING_GLASS_FX_ADD_SOURCES`: every variant with an
alpha-dependent `discard` is exact, with or without the coordinate line; every variant
without one is not. The Vita GPU is of the same family, so the test also keeps the
programs in the class the full program is in today.

`fx_add_fog_free` (requires `fx_add_lean`) also drops the `fogged` call when it returns its
argument for every fragment of the packet: distance fog and liquid fog are off in the
uniform payload, and each fog volume is either off or separated from every eye-to-triangle
hull by an axis-aligned plane of its box, with a margin of 4 units plus 0.1 percent of the
largest coordinate. Then `fogLength` is zero and `mix(rgb, x, 0)` is `rgb`. Packets with
more than 2,048 triangles are not scanned and keep the fogged program.

Geometry, order, textures, uniform words, blend and depth state are unchanged. Both
programs declare the full program's four varyings in its order, so the shared vertex
program feeds them the same interpolants. A program that fails to build leaves its packets
on the route they had before and logs `program failed`.

Why it exists: on the Vita the jlair2 fight spends up to 117 ms per frame waiting for the
GPU while the Jabberwock breathes fire, and masking the additive effect class removes
almost all of it. The breath is large additive sprites (`prj_jabberwock_breath`, scale 5)
that cover the screen many times over, each fragment running the full actor program.

`LOOKING_GLASS_FX_ADD_SOURCES` (host probe builds only) reads replacement sources for the
two programs from an absolute folder; it exists for the bisect above.

`LOOKING_GLASS_JABBERWOCK_FIRE` is a host oracle fixture, compiled only into host probe
builds: the boss starts its fire breath whenever it is free to act and Alice takes no
damage. The fight tapes diverge on the host before the boss ever breathes, so without it
no host proof draws the breath.

Host proof and the console package live outside Git, in the task evidence folder.
Console speed and picture are measured by the device slot only.
